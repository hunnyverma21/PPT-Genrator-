# SlideCraft — PowerPoint Generator

A browser-based presentation builder. Add slides, edit titles and bullet points, choose a theme, preview your slides, and export a `.pptx` PowerPoint file.

## Features
- Add, select, and delete slides
- Edit presentation title, slide titles, and content
- Each line of slide content becomes a bullet point
- Title slide or title + bullets layout
- Four themes: Midnight Blue, Modern Violet, Forest Green, and Clean Minimal
- Live slide preview
- Export a real PowerPoint `.pptx` file

## How to run
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or another modern browser.
3. Add and edit your slides.
4. Click **Download PowerPoint (.pptx)**.

The PowerPoint export library is loaded from jsDelivr, so an internet connection is required when opening the app.

## Files
- `index.html` — app structure
- `style.css` — styling
- `script.js` — slide editor and PPTX export
